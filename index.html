Firebase beállítási segédlet

Projekt: exporting-89727

Ahhoz, hogy a telefonodról feltöltött képek azonnal megjelenjenek a laptopodon, a Firebase projektben engedélyezni kell a Cloud Firestore adatbázis írását és olvasását:

Firestore Database → Rules

Nyisd meg a Firebase Console-ban a Build → Firestore Database → Rules fület, illeszd be az alábbi szabályt, majd kattints a Publish gombra: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomCode} {
      allow read, write: if true;
      match /photos/{photoId} {
        allow read, write: if true;
      }
    }
  }
}
