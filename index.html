Firebase beállítási segédlet

Projekt: exporting-89727

Ha új a Firebase projekted, és a szoba létrehozása vagy a feltöltés jogosultsági hibát jelez, ellenőrizd az alábbi két beállítást a Firebase Console felületén:

1. Firestore Database Rules

Nyisd meg a Firestore Database → Rules fület, és illeszd be ezt a szabályt: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomCode} {
      allow read, write: if true;
      match /photos/{photoId} {
        allow read, write: if true;
      }
    }
  }
}
2. Anonymous Authentication (Opcionális)

Az Authentication → Sign-in method menüpontban engedélyezheted az Anonymous belépést, de az alkalmazás enélkül is működik.
